# astro-resend-router

An astro integration that turns [Resend](https://resend.com/) into a lightweight mailing list system by using a webhook and API endpoint.

Astro Resend Router provides a single API endpoint that lets:

- Anyone join a configured list by sending an email.
- Authorized senders broadcast messages to all subscribers.

To see how to get started, check out the [package README](./package/README.md)
